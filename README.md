# 🏙️ Gurgaon Real Estate Data Analysis

This project analyzes Gurgaon real estate data using **Python, Pandas, Matplotlib, and Seaborn**.  
The goal is to clean, prepare, and explore the dataset to answer key business questions about property prices, locality trends, builder strategies, and RERA approval impact.

---

## 📂 Project Workflow

### 1. Data Cleaning & Preparation
- Standardized column names (lowercase, underscores, removed spaces & brackets).
- Cleaned numerical columns (`price`, `rate_per_sqft`) by removing symbols and converting to integers.
- Cleaned categorical columns (`status`, `rera_approval`, `flat_type`).
- Removed duplicate records.

### 2. Exploratory Data Analysis (EDA)
The following questions were answered:

1. **Which is the costliest flat?**  
   → Identified the flat with the maximum price, including details like BHK, locality, society, builder, and RERA status.

2. **Which locality has the highest average price?**  
   → Computed average prices per locality and highlighted the most expensive one.

3. **Which locality has the highest rate per square foot?**

4. **Do ready-to-move properties cost more than under-construction properties?**

5. **Do RERA-approved properties command a price premium?**

6. **How does area impact price?**  
   → Scatter plot visualization.

7. **Which BHK configuration is most expensive on average (rate per sq. ft)?**

8. **Which property type (Apartment, Floor, Plot) is the costliest?**

9. **Do certain builders or companies consistently price higher?**  
   → Printed top 5 companies and top 5 builders.

10. **Are larger homes always more expensive per square foot?**  
    → Scatter plot visualization.

---

## 📊 Visualizations
- Scatter plots for **Area vs Price** and **Area vs Rate per Sq. Ft.**
- Comparative analysis of **Ready-to-Move vs Under-Construction** properties.
- Builder and company pricing trends.
